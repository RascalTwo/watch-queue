Tag rules

One rule per line: Tag = phrase, phrase, …. New items whose title, creator, or link contains a phrase (as whole words) get the tag. In links, dashes and slashes count as spaces, so space show matches …/space-show-s3; a piece of a link like example.com/tv/ works too. ALL-CAPS phrases match exact case only; others ignore case. Lines starting with # are ignored.
